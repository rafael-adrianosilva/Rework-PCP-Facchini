1. VISÃO GERAL
   O sistema "Facchini PCP" é uma plataforma web desenvolvida para o Planejamento
   e Controle da Produção. Seu objetivo principal é centralizar a visualização e
   o gerenciamento de documentos técnicos (PDFs) e conjuntos de arquivos (Kits),
   organizados por regiões geográficas da empresa.

2. TECNOLOGIAS UTILIZADAS
   - Backend: PHP 8.x (Estruturado)
   - Frontend: HTML5, CSS3 (Vanilla), JavaScript (ES6+)
   - Ícones: FontAwesome Free 5.x
   - Armazenamento: Sistema de arquivos local (diretório documentos/)
   - Banco de Dados: Não utilizado nesta versão (gerenciamento via filesystem)

3. ESTRUTURA DE DIRETÓRIOS
   / (raiz)
   ├── index.php             # Dashboard principal e visualização de arquivos
   ├── uploads.php           # Interface de gerenciamento e upload de arquivos
   ├── favicon.png           # Ícone do site
   ├── css/                  # Estilização (global, nav, footer, modal, index)
   ├── js/                   # Lógica client-side (index.js, upload.js)
   ├── assets/               # Imagens, logotipos e biblioteca FontAwesome
   ├── documentos/           # Repositório de arquivos (pdfs/regiao/tipo/...)
   └── php/                  # Backend funcional
       ├── components/       # Partes reutilizáveis (nav, footer, modals)
       ├── actions/          # Scripts PHP para requisições AJAX (excluir, criar pasta)
       └── upload_files.php  # Lógica de processamento de upload

4. FUNCIONAMENTO DO FRONTEND (JavaScript & UI)
   - Navbar (nav.php):
     * Permite alternar entre os temas Claro e Escuro (persistido no localStorage).
     * Seletor de Região: Filtra o conteúdo de todo o sistema. Se nenhuma região
       for selecionada, exibe "Região não definida".
   - Dashboard (index.php):
     * Visão Global: Exibe cards com estatísticas de todas as regiões.
     * Visão Regional: Lista PDFs e Kits da região selecionada.
     * Pesquisa: Barra de busca em tempo real que filtra arquivos e abre pastas
       automaticamente se houver correspondência interna.
   - Sistema de Modais (modals.php):
     * Todas as interações (sucesso, erro, confirmação de exclusão) utilizam
       modais personalizados para uma experiência fluida sem alerts nativos.

5. FUNCIONAMENTO DO BACKEND (PHP & Lógica)
   - Regiões Válidas: Existe uma "única fonte de verdade" ($regioes_validas) em
     diversos arquivos (nav.php, index.php, upload_files.php) para garantir a
     integridade dos dados.
   - Upload de Arquivos:
     * Upload Normal: Envia PDFs individuais para a pasta 'upload_normal'.
     * Upload de Kits: Permite enviar pastas inteiras ou múltiplos arquivos para
       uma pasta específica (Kit) no servidor. O sistema preserva a estrutura de
       subpastas se enviadas via "Selecionar Pasta".
     * Limites: Aceita apenas arquivos .pdf de até 5MB.
   - Ações de Gerenciamento:
     * excluir_item.php: Apaga arquivos ou pastas inteiras de forma recursiva.
     * limpar_coluna.php: Esvazia todos os arquivos de uma categoria específica.
     * criar_pasta_kit.php: Cria novos diretórios de destino para o modo Kit.

6. FLUXO DE NAVEGAÇÃO
   - Ao entrar no sistema (index.php), o usuário vê o dashboard global.
   - Ao selecionar uma região na Navbar ou nos Cards, a URL recebe o parâmetro
     ?regiao=NomeDaRegiao, e o sistema carrega os arquivos específicos.
   - O botão "Upload" leva o usuário para uploads.php?regiao=..., mantendo o
     contexto da região atual para evitar erros de envio em locais errados.

7. DESIGN E ESTÉTICA
   - O projeto utiliza CSS Variables (Custom Properties) para gerenciar o tema
     dinâmico.
   - Possui design responsivo, adaptando-se a diferentes tamanhos de tela.
   - Utiliza efeitos de vidro (glassmorphism) e transições suaves nas modais.
